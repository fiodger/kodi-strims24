Kodi 19+ / Python 3, także Android TV. Instalacja z ZIP-a lub aktualizacja
z repozytorium Fiodger - Strims24. Identyfikator plugin.video.strims24 jest
niezmieniony, więc nowy ZIP aktualizuje obecną instalację.

Menu: Obecnie live lub dyscyplina → dzisiaj/jutro → wydarzenie → źródło.
Godzina po lewej: zielona dla live, niebieska dla nadchodzących wydarzeń.
Status live nie gwarantuje dostępności każdego zewnętrznego źródła.

Test 18.10.2026: 21 testów kodu; lista live, odbiór WSS, aktualizowanie HLS
oraz pobranie prawidłowego fragmentu MPEG-TS. Test na Android TV do potwierdzenia.

Nie wykonuje skryptów zewnętrznych. Obsługuje nowy protokół echo i jawne HLS.
Brak obsługi CAPTCHA, logowania, DRM oraz dowolnych odtwarzaczy JavaScript.
